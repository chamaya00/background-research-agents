# Series: learning in public - product data scientist to data engineer

## Premise

A product data scientist moving into data engineering and agentic AI, writing
each week's research and each week's own work into one long-form issue, with
2-3 LinkedIn posts cut from it. *The author, in #72: "learning in public:
product data scientist -> data engineer in the agentic era."*

## Audience

The same three audiences [`style.md`](../style.md) sets, in the same priority
order: data science and data engineering hiring managers and recruiters
first, people making the same career move second, anyone interested in agent
evals and AI measurement third. This file does not repeat those lines; it
only tracks whether the series as a whole is still reaching them.

## Installments

None claimed yet. A row is one installment - a Substack issue together with
every cut post made from it - not one row per piece. It is added here only
when the Substack issue reaches `status: posted` in its own front matter; a
draft or an abandoned issue does not take a number or appear in this list. The
issue claims the row's number; each cut post carries a `cut_from:` field
naming that issue and takes its number rather than claiming one of its own,
landing in the row's Cut posts column as it posts. Once the first issue is
posted, add a row here in this form:

| # | Status | Substack issue | Cut posts |
|---|--------|-----------------|-----------|
| - | - | - | - |

## Open threads

None yet - there is no posted installment to have promised one. Once an
